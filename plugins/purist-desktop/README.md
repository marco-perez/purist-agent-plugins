# Purist

Create and refine designs with your AI agent.

Bring Cursor, Claude Code or Codex into Purist to create layouts, inspect layers and styles, and refine text and spacing. Review changes with screenshots of your canvas.

Requires the Purist app to be open on the same computer. Sign in to Purist before starting a design workflow.

See [installation, updates, removal and troubleshooting](INSTALLATION.md). The bundled `purist-design` skill guides inspection → focused edits → screenshot → save verification. Tool replies describe the current schemas and relevant guides.

Design content and screenshots become available to your chosen agent and may be sent to that agent's model provider. This package adds no telemetry or credential storage. Purist account features and generation have their own authentication, network and billing requirements; this package does not establish that those features have been validated.

Local desktop execution is the supported target. A web session, cloud agent, remote SSH host, container or WSL environment may have a different loopback network. Do not expose the port publicly or change the endpoint to work around that. Use a client running on the Purist computer. Claude Desktop chat extensions and hosted MCP are separate integrations.
